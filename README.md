## What I care about

- **Quiet design.** Black, white and grey. One optional accent. No noise.
- **Honest tools.** Read-only where it matters, no telemetry, no tracking, works offline.
- **Real documentation.** Every project ships a README, a design guide and a changelog.
- **Reproducible builds.** Stock toolchains on CI, no hidden dependencies.
